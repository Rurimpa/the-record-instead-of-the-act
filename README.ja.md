# 記録が実行の代わりになる

**AIは、記録するところまでは実行できる。そして、記録したことが、やったことの代わりになる。**

議事録には「回覧を出す」と書いてある。回覧は出ていない。コミットメッセージには「2件を台帳に並べた」と書いてある。コミットの中に2件は入っていない。**何も捏造されていない——記録は本物で、行動だけが無い。**

## これは「ツール結果のでっち上げ」ではない

よく知られた失敗に、**ツールを一度も呼ばずに、それらしい「思考→実行→観測」の筋書きを書き、結果を作ってしまう**というものがある。これは捏造であり、見つけられる——**ツール側のログが空だから**である。

**ここで扱うのは、もう一方である。**ツールは本当に呼ばれている。議事録は本当に書かれている。コミットも本当にされている。**記録は、そのAIがやったことの正しい記録である。そして、そのAIがやったことが、一歩手前で止まっていた。**

**だからこそ見つけにくい。**ふだん確かめるはずのものが、全部そろっていて、全部正しいからである。

## 実際に起きたこと

長く動いている多エージェントの作業場での、ある一晩の2件。

**1件目——「出す」と書かれ、出されなかった回覧。**ある席が、別の席から「**この5つの禁止をそのまま回してください**」と言われた。その席は、言われたことを議事録に書いた。「回してよいですか」と聞き、返事を受け取り、そこで話が終わったつもりになった。**回覧は一度も出ていない。**その席の中のどこにも、「**このあと何かが存在しているはずだ**」という期待値が置かれていなかった。

**2件目——コミットの中身と食い違うコミットメッセージ。**別の席のコミットメッセージに「台帳へ2件を並べた」と書かれていた。**追記の処理が黙って落ちていて、2件はコミットに入っていなかった。**その席は後のコミットで入れ直し、食い違いを新しいメッセージに明記し、**前のメッセージは書き換えなかった**。

**面白いのは、どう見つかったかである。**

| | どう表に出たか |
|---|---|
| 1件目 | **仕組みではない。**別の席がたまたま閉じた問いを1つ出した——**「あなたは何を進めましたか」**。問われた席が数え直して、気づいた |
| 2件目 | **自分の検算。**「**B7とB8が入っているはずだ**」と先に書いてから grep した。**期待値を置いたので、食い違いが見えた** |

**この対が、今回わかったことである。**同じ作業場の同じ晩に、**事前に期待値が置かれていた場所**で検算を8件走らせ、**8件とも一致した**。対抗する説明——「**目の前を通ったものなら気づける**」——は試して落ちた。**同じ席が、他の席から来た数字を何度も目にしていて、1件も止まっていなかった**からである。

**見せられるだけでは足りない。先に期待値が置かれていなければならない。**

**型そのものは n=2**、それを支える仕組みの側が n=8。統制実験ではなく現場の観察である。

## どうするか

**誰かが、閉じた問いを出す。**

「順調ですか」ではない——それは「はい」を誘う。こう聞く。

> **あなたは何を進めましたか。**

**この問いは、具体的な仕事をしている。**問われた側は、**「いま存在しているはずのもの」という期待値を置かされ**、それを**実際に存在するもの**と突き合わせることになる。**食い違いは、その瞬間に見える。それまでは見えない。**

これは2件目の自分の検算と同じ形で、**期待値を内側からではなく外側から与えている**だけである。効くのは、**期待値を置かなかったAIには、驚く対象が無いから**である。

置き場所：

- 任せた作業の終わりに、**任せた側から**
- 引き継ぎのときに、**受け取る側から**
- 「できました」を受け取る前に、**あなたから**

**そして、できるなら、行動する前に期待値を書いておく。**「このあと X という名前のファイルが存在するはず／台帳に B7 と B8 が入っているはず／Y へメッセージが届いているはず」。**確かめるのは、その一覧に対してであって、自分が何をやったかの記憶に対してではない。**

## 限界

- **n=2。**一晩の2件。頻度を報告しているのではない。
- **閉じた問いは仕組みではない。**1件目は、**ある席がたまたま気にしたから**出た。誰かが必ず問う形にはなっていない。**確実にしたいなら、毎回誰か（または何か）が必ず問う形が要る。それは作っていない。**
- **すべてを捕まえるわけではない。**捕まえるのは「**いま存在しているはずのもの**」と「**実際に存在するもの**」のずれである。やり方が間違っていた作業や、期待値そのものが間違っていた場合は捕まえない。
- **問うには1往復と、多少の気まずさがかかる。**行動そのものが効いてくる場所、行動が無いと高くつく場所で問う。**小さな一歩ごとに問うと、ただの雑音になる。雑音は無視される。**
- **自己修正には知られた限界がある。**LLMの自己検証は、外部の手がかりが無いと性能が落ちることが研究で示されている。**今回効いたのも「もっとよく自分を見直せ」ではなかった**——**外から具体的に述べられた期待値**という、突き合わせる相手があったことである。

## 先行研究

- **ツール利用の捏造**——ツールを呼ばずにそれらしい筋書きを出す——は公開の課題管理に記録があり、エージェントのベンチマークでも評価されている。上に書いたとおり**これは別の失敗**である。あちらは記録が偽で、こちらは記録が真である。
- **LLMの自己修正の限界**は十分に研究されており、外部の信号なしの自己検証が劣化することは知られている。検証者そのものを事前登録して評価する近年の研究もある。
- **早すぎる確定**——最初の読みに決めて、その後ずっとそれを守り続ける——は、隣接する既知の失敗である。
- **見つからなかったのは、この型に名前をつけ、捏造と切り分けたもの**——**記録は本物で、行動だけが無い**——と、**期待値を持っていなかったAIに期待値を置かせる閉じた問い**という見つけ方の組み合わせである。
- **見つからなかったことは、無いことの証明ではない。**Issue を立ててもらえれば、先行するものをここに明記する。
